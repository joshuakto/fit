## Instructions

`README.md` reflects the current stable release, not unreleased work. The standard is in the "Documentation"
section of @docs/CONTRIBUTING.md which is the source of truth.

Flag a README change that documents behavior not yet in the latest stable release as if it were current, or
that removes a still-accurate description of released behavior. Wording fixes and corrections to
already-released behavior are fine.
